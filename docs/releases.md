# Releases

Theumst 0.0.7 replaces the previous Web Demo with the accepted Sanctuary, Orbit, realm book and notebook design. It connects the design to persistent books, notes, completion, saved positions and discovery. Knowledge objects gain an optional name; collection removal preserves checked-off Mind Palace knowledge. The homepage and dashboard retain their accepted design.

Christopher selected 0.0.7 for this delivery, superseding the previously proposed 0.0.4 and correcting the earlier 0.2.x numbering. Historical tags remain unchanged. API compatibility metadata and third-party package versions remain independent.

## Publication identity

Run the [required verification](testing.md), resolve failures, and record exact commands, setup and results. Publish the verified tree on `main`. Create an annotated `v0.0.7` tag on that exact commit and a GitHub release referencing that tag. Preserve legacy branches until their separate migration route decides their disposition.

Record the source commit, clean-tree status, tag object, release URL and SHA-256 of deployment artifacts. Keep configuration/secrets outside public assets. A release built from extra uncommitted source is not identical to its tag.

Deploy the published revision to COM through [operations](operations.md) after verified backup. Record the deployed revision and post-deployment results. CN is outside this delivery. Complete the implementing issue only after implementation, verification, main publication, tag/release and COM deployment are recorded. The annotated release and its GitHub release notes own the resulting source commit, artifact digests and COM deployment observations. The earlier [0.1.0 release](https://github.com/Christopher8187/theumst/releases/tag/v0.1.0) records the previous Demo implementation.

See the [0.0.7 verification record](history/release-0.0.7.md) for local checks, browser coverage and backup verification.
