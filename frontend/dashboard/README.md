# Signed-in dashboard

The dashboard provides API keys, Web Demo access requests, and permitted content or administrative tools inside the shared desktop. Profile and its Details and Subscriptions tabs open in a separate window. Access determines both available navigation and server authorization. Users do not gain access by entering a page URL manually.

`src/App.vue` mounts `frontend/shared/DesktopApp.vue`, which owns window navigation, visibility, the scene and Settings. `src/components/DashboardTools.vue` renders the permitted tools and accepts `initialRoute` and `language`. It emits `route-change`, `back-profile` and `session-expired`; the parent opens Login when a tool receives 401. [Frontend architecture](../../docs/architecture/frontend.md#desktop-navigation-and-entry-urls) owns the visible root URL and compatibility entry links. Keep this component mounted while hiding its window so tool drafts remain available. `src/composables/useDashboardTools.js` owns tool state and the existing API actions. `src/router/` supplies route permissions. Arbitrary SQL remains restricted to authorized accounts.

Media can publish a News post and optionally queue one email announcement for confirmed subscribers. Its separate email introduction is previewed through `/api/content/media/email-preview` inside a sandboxed frame. Previewing sends no mail. The announcement checkbox starts unchecked, draft posts cannot announce, and a queued announcement cannot be sent again by editing the post. `src/composables/useMediaPosts.js` handles these actions and retains the draft after a failed save.

Run `npm ci`, `npm test` and `npm run build` here. The focused tests exercise route access and announcement/preview behavior against controlled API responses; backend and browser acceptance still cover authorization, real persistence and rendering. Local Vite uses port 5174 and the dashboard path prefix. Read [administration](../../docs/administration.md), [security](../../docs/security.md) and [backend test modules](../../backend/python/tests/README.md) before changing role-sensitive behavior.
